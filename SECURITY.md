# Segurança

Este é um projeto público e sintético.

Não abra issues contendo:
- dados pessoais;
- documentos reais;
- credenciais;
- tokens;
- processos;
- segredos empresariais.

Antes de publicar mudanças, execute:

```bash
python scripts/verificar_publicacao.py
python -m unittest discover -s tests -v
```
