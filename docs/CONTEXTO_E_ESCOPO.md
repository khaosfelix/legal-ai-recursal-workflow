# Contexto e escopo

O projeto surgiu de uma rotina de análise recursal em contencioso cível massificado de instituição financeira.

O objetivo não era criar um sistema jurídico novo para substituir as ferramentas existentes. A operação já tinha sistemas próprios, fluxos de cadastro e uma calculadora recursal externa.

A automação foi construída para reduzir o trabalho antes dessas etapas:

- ler a íntegra;
- localizar a decisão certa;
- organizar prova e histórico;
- analisar possibilidade de ED;
- analisar recurso subsequente;
- calcular prazos;
- apurar trânsito;
- calcular exposição;
- organizar OBF;
- gerar posicionamento;
- produzir a referência DOCX;
- entregar os campos prontos para cadastro;
- e, quando a fase era sentença, entregar também os campos necessários para preencher a calculadora externa.

A versão pública preserva esse desenho, mas usa somente casos e regras sintéticos.
