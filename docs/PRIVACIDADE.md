# Privacidade

O contexto genérico de instituição financeira foi mantido porque faz parte do problema que motivou o projeto.

A versão pública não identifica a organização, o escritório ou os sistemas utilizados.

Foram removidos:
- nomes;
- códigos internos;
- processos;
- contratos;
- documentos;
- screenshots;
- políticas privadas;
- tabelas;
- bases internas;
- credenciais;
- endpoints.

A calculadora mostrada no repositório não é a ferramenta institucional. É apenas uma representação sintética dos campos que a automação preparava para preenchimento.
