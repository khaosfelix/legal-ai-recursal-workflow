# Mapa de análise da íntegra

A leitura pode envolver:

- inicial;
- contestação;
- subsídios;
- réplica;
- contratos;
- extratos;
- logs;
- comprovantes;
- tutelas;
- sentença;
- ED;
- recursos;
- contrarrazões;
- acórdão;
- cumprimento.

A extração deve permitir responder:

- qual decisão está vigente?
- o que foi pedido?
- o que foi provado?
- existe matéria para ED?
- existe recurso subsequente?
- existe compensação?
- qual é a obrigação?
- qual é a exposição?
- existe risco de preclusão?
